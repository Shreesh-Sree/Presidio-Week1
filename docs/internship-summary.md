# Internship Week-1 Summary

DevInsight-Lab is my Week-1 internship submission around developer productivity analytics. I tried to make the repo feel like something connected to real SDE work instead of a collection of unrelated exercises.

## What I Completed

- Documented Git branching, pull requests, reviews, merges, and conflict resolution.
- Built HashMap-based Python scripts for activity logs and contributor frequency.
- Built recursive Python scripts for folder and dependency analysis.
- Designed a SQL schema for developers, repositories, commits, pull requests, and reviews.
- Wrote SQL queries using joins, grouping, HAVING, and subqueries.
- Added indexing notes and a PR approval transaction workflow.
- Updated the system design after studying the provided architecture PDF.
- Added SDLC notes and a Week-1 learning journal.
- Added GitHub Actions CI for structure and Python syntax checks.

## What Felt Most Useful

The most useful part was connecting the concepts. HashMaps, recursion, SQL, and system design felt more meaningful once they all used the same engineering workflow domain.

## What Is Still Rough

- The Python scripts use sample in-memory data.
- The SQL has not been executed against a live PostgreSQL instance yet.
- The CI checks are simple.
- There is no frontend dashboard yet.

## What I Would Improve Next

I would add tests, run the SQL in PostgreSQL, and build a small API that receives fake GitHub events. That would make the project feel closer to a working platform.

## Final Reflection

This repo is not perfect, but it helped me practice Week-1 concepts in a practical way. I understand the tradeoffs better now, especially around schema design, indexes, transactions, and system design scope.
